# TANSHU DIGITAL TOOLS
**ALL IN ONE DIGITAL WORKSPACE**

Premium bilingual (Hindi / English) responsive workspace prototype for CSC centers, cyber cafés and digital service professionals.

## Preview locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Current phase
This branch contains the UI foundation and navigation prototype only. Maker cards and directory entries that are not implemented are clearly marked **Coming Soon**. No actual document/photo processing is claimed in this preview.

## Design features
- Hindi / English toggle in the top bar
- Responsive desktop sidebar and mobile bottom navigation
- Searchable tool directory, category cards, favorites and recent activity
- Maker tools prioritized above category directory
- Dark / light appearance toggle
- CSC Center and Cyber Cafe workspaces
- Privacy-conscious product direction

## Safety and trust
Government and institutional document layouts must only be used for legitimate, authorized purposes. Unissued templates should be visibly marked SAMPLE / DRAFT. Never use this app to fabricate government IDs, official certificates, signatures or verification codes.
